# 06 Design Philosophy

## Core Vision

The website must feel like entering a premium music studio rather than a
coaching institute.

The experience should communicate: - Confidence - Creativity -
Performance - Professionalism - Craftsmanship

## Design Keywords

Luxury, Editorial, Cinematic, Minimal, Warm, Authentic.

## Visual Inspiration

The supplied screenshots define: - Full-width imagery - Large
typography - Minimal navigation - Dark backgrounds - High contrast
text - Elegant whitespace

Never overcrowd sections. Every section should breathe.

## Content Priority

1.  Photography
2.  Headline
3.  Supporting copy
4.  Primary CTA
5.  Secondary actions

## Design Rules

-   Every section must have one clear focal point.
-   Keep layouts asymmetrical where appropriate.
-   Use subtle motion.
-   Never use clip-art or generic illustrations.
