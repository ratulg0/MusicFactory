# Design Bible

## Vision

The website should feel like a premium music studio---not a tuition
website.

### Emotional Goals

-   Inspire parents
-   Excite students
-   Showcase professionalism
-   Build trust
-   Encourage enrollment

## Visual Personality

Editorial • Cinematic • Elegant • Warm • Minimal • Confident

## Design Principles

1.  Photography first.
2.  White space is a feature.
3.  One focal point per section.
4.  Motion supports storytelling.
5.  Every section should end with a clear next action.

## User Journey

Curiosity → Trust → Confidence → Action
