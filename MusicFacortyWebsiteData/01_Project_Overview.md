# 01 Project Overview

## Vision

Build a premium website for **The Music Factory by Archit** that feels
luxurious, modern and inspiring.

The visual inspiration comes from the provided reference screenshots: -
Full-screen hero - Editorial typography - Dark luxury theme - Minimal
navigation - High-quality imagery - Smooth interactions

The educational content must come from the supplied academy PDFs: -
Academy philosophy - Young Musician Program - Workbook concepts -
Teaching methodology - Performance culture - Music Circle - Motto

## Goals

1.  Inspire trust.
2.  Increase admissions.
3.  Showcase academy culture.
4.  Highlight curriculum.
5.  Encourage trial bookings.
6.  Be mobile-first.
7.  Score above 90 in Lighthouse.

## Audience

Parents of children (6--18) Teenagers Music enthusiasts Potential
collaborators

## User Journey

Landing → Hero → About → Programs → Gallery → Testimonials → Contact →
Trial Class

## Success Criteria

Responsive Accessible SEO friendly Fast Elegant
