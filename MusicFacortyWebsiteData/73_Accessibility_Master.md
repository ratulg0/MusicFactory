# 73 Accessibility Master Guide

## Goal

Target WCAG 2.2 AA compliance.

## Principles

-   Perceivable
-   Operable
-   Understandable
-   Robust

## Requirements

-   Semantic HTML
-   Keyboard navigation
-   Visible focus
-   Logical heading hierarchy
-   Sufficient color contrast
-   Descriptive alt text
-   Accessible forms
-   Reduced motion support

Acceptance: Lighthouse Accessibility \>=95.
