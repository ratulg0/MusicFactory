# Project Constitution

## Non-negotiable Rules

-   Semantic HTML only.
-   CSS variables for all reusable values.
-   No framework dependencies.
-   Modular JavaScript.
-   Mobile-first responsive design.
-   WCAG 2.2 AA target.
-   Lighthouse 95+ where practical.
-   Reusable components before pages.

## Decision Hierarchy

Master Context \> Design Bible \> Component Docs \> Page Docs.
