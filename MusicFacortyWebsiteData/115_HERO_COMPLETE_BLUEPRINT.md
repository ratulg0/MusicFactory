# Hero Complete Blueprint

## Purpose

The Hero is the emotional entry point of the website. Within five
seconds it should communicate: - Premium music education - Confidence -
Performance - Creativity

## Visual Composition

-   Full viewport height (100vh).
-   Cinematic background image or muted looping video.
-   Dark gradient overlay (60--70%).
-   Left-aligned content on desktop, centered on mobile.
-   Floating scroll indicator.

## Content Hierarchy

1.  Eyebrow label
2.  Main headline
3.  Supporting paragraph
4.  Primary CTA
5.  Secondary CTA

## Responsive

Desktop: split composition. Tablet: centered with reduced width. Mobile:
stacked layout.

## Accessibility

Contrast ratio \>= 4.5:1. Video must not autoplay with audio.
