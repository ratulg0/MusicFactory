# 27 Gallery Section Specification

## Purpose

The Gallery demonstrates the academy atmosphere, student performances,
rehearsals and events. It should build trust through authentic
photography.

## Layout

-   Full-width section
-   Masonry grid on desktop
-   2-column grid on tablet
-   Single column on mobile

## Categories

-   Classes
-   Live Performances
-   Music Circle
-   Graduation Showcase
-   Practice Sessions
-   Studio Moments

## Image Requirements

-   High-resolution WebP
-   Warm color grading
-   Consistent aspect ratios where practical
-   Dark overlay on hover

## Interactions

-   Hover zoom (1.05x)
-   Fade overlay
-   Image title and category appear on hover
-   Lightbox with keyboard support
-   Previous / Next navigation

## Accessibility

-   Meaningful alt text
-   ESC closes lightbox
-   Arrow keys navigate images
-   Focus trapped inside lightbox

## Acceptance Criteria

Visitors should understand the academy environment before reaching the
contact section.
