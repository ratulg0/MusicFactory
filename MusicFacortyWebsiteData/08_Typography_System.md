# 08 Typography System

## Heading Font

Elegant serif.

## Body Font

Modern geometric sans-serif.

## Scale

Hero: 72px H1: 56px H2: 40px H3: 30px Body: 18px Small: 15px

## Line Height

Headings: 1.1 Body: 1.7

## Rules

Maximum paragraph width: 70 characters. Avoid centered paragraphs except
in hero sections. Maintain consistent heading spacing.
