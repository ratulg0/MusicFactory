# 07 Color System

## Primary Palette

Background: #0B0B0B Surface: #171717 Card: #202020 Border:
rgba(255,255,255,.08) Primary Gold: #C89B3C Secondary Gold: #D7A44D
Primary Text: #F5F2EB Muted Text: #A5A5A5

## Usage

Background occupies \~80% of the interface. Gold is reserved for CTAs,
links, active navigation and highlights. Muted text is used only for
descriptions.

## States

Hover: brighten gold by 8%. Focus: gold outline. Disabled: muted gray.
Error: warm red. Success: muted green.
