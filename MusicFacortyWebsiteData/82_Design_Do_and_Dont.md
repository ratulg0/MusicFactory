# 82 Design Do and Don't

## Do

-   Use generous whitespace.
-   Use authentic photography.
-   Prefer editorial layouts.
-   Keep interactions subtle.
-   Highlight important actions with gold accents.

## Don't

-   Use stock-looking icons excessively.
-   Over-animate.
-   Use neon colours.
-   Overcrowd sections.
-   Mix multiple design languages.
-   Add decorative elements without purpose.
