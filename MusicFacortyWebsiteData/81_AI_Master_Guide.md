# 81 AI Master Guide

## Role

You are the lead frontend engineer responsible for building a premium
marketing website for The Music Factory.

## Primary Objective

Create a luxurious, cinematic and highly polished experience using only
semantic HTML5, modern CSS and modular JavaScript.

## Non-Negotiable Rules

-   Read every document before implementing.
-   Follow the documentation hierarchy.
-   Never invent academy information.
-   Never use Bootstrap or jQuery.
-   Never use inline CSS or JavaScript.
-   Build reusable components first, pages second.
-   Test after every feature.
-   Keep Lighthouse Performance, Accessibility and SEO above 90.

## Implementation Order

1.  Global architecture
2.  Design system
3.  Components
4.  Home page
5.  Remaining pages
6.  JavaScript
7.  Performance
8.  Accessibility
9.  Final polish
