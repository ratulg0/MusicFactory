# 65 HTML Architecture

## Philosophy

Use semantic HTML5 throughout the project. Every page must follow the
same structural pattern.

## Standard Structure

\<!DOCTYPE html\>
```{=html}
<html>
```
```{=html}
<head>
```
```{=html}
<body>
```
```{=html}
<header>
```
```{=html}
<main>
```
```{=html}
<footer>
```
## Rules

-   One H1 per page.
-   Landmark elements only once.
-   Semantic sections.
-   No unnecessary div nesting.
-   IDs only for navigation or scripting.
